# 업무 확장 검토 기록

기존 저장 키 d-smart-erp-v1, products/movements/locationStocks/portfolioModules/erp19 구조는 유지한다. operations 하위에 전표, 입출고 원장, 변경 이력, 담당 역할을 추가한다. 기존 전표는 최초 한 번 이관하며 재로드 시 중복 생성하지 않는다.

구매·판매·결재·물류 화면은 새 단일 전표 흐름을 사용하고 기존 배열에 결과를 동기화한다. 재고는 총재고와 창고별 합계를 먼저 검증한 뒤 원장, 이동 기록, 전표 상태를 함께 저장한다. 저장 오류 시 변경 전 객체를 유지한다. 취소는 원본 삭제 없이 반대 원장을 기록하며 재취소를 차단한다.

첨부는 FileReader로 읽어 전표에 저장한다. 사용자 문자열은 HTML 이스케이프한다. 승인 전 입출고, 중복 입출고, 부족 재고, 잘못된 날짜·금액·수량, 역할에 맞지 않는 처리를 거부한다.

기존 기능 19개 회귀 검증과 새 기능 33개 검증 통과. 검증 코드는 tests 폴더에 포함하며 npm test로 재실행한다. 이 테스트는 독립 메모리 DOM을 이용한다. 서버 로그인, 공유 데이터베이스, 법적 효력의 전자결재·회계 처리는 이 변경의 구현 범위에 포함하지 않는다.
